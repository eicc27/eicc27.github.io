# eicc27.github.io

GitHub Pages 个人主页初版。

## 当前内容

- 一页式首页结构
- 响应式布局，适配桌面端和移动端
- 基础滚动显隐动画
- 预留了关于我、项目、近况、联系方式几个板块

## 你接下来最值得改的地方

1. 把首页标题和介绍文案改成你的真实信息。
2. 把三个项目卡片替换成你自己的仓库或作品。
3. 把邮箱按钮改成真实邮箱或其他联系方式。

## 本地预览

如果要在本地看效果，可以在仓库目录运行：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。
