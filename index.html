02 / Interests / Studio

钢琴和监听是另一条主线，不是附属装饰。

除了摄影和徒步，平时也会把钢琴、监听和房间校准当作持续打磨的工作区。这里用空间图和读数， 把这套 setup 的逻辑讲清楚。

Actual Setup / 2.1

Genelec 8330A + 7350A + SL GRAND 88

GLM snapshot · 2026-03-16

这块不是概念图，而是你现在真实在用的 2.1 工作区：一对 Genelec 8330A 负责左右声像，SL GRAND 88 占住中轴， Left Side 7350A 把低频往下补到底。上面的 honeycomb map 负责把摆位讲清楚，下面这组 readout 则把房间、 校准和左右声道状态讲完整。

Working Notes

实际使用时最值得盯的是中轴、左右 trim 接近度，以及低频模式点。

这套摆位的重点不是把器材堆满，而是让钢琴、监听和听音位三者沿同一条中心线工作。GLM 结果里左右 trim 只差 0.3 dB，说明主声像已经比较稳；真正需要长期记住的是 47.2 / 106.2 / 146.1 Hz 这些房间模式，以及 sub 在 27.6 Hz 这一带的行为。
